# Jack OS

An operating system for the Hack computer built in the Jack language as part of the **Nand2Tetris** course.

Implements core modules including memory management, math utilities, screen and keyboard drivers, and system-level I/O.

## Build and Run
1. Open the Nand2Tetris IDE  
2. Load and compile all `.jack` files  
3. Run the generated `.vm` files in the VM Emulator  

## Files
- Memory.jack  
- Math.jack  
- Screen.jack  
- Keyboard.jack  
- String.jack  
- Array.jack  
- Output.jack  
- Sys.jack
